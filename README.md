# Blog Application

A full-stack blog application developed as a web development project.

## Features
- User Registration and Login
- Create New Blog Posts
- View Blog Posts
- Edit Existing Blog Posts
- Delete Blog Posts
- MongoDB Database Integration
- REST API using Node.js and Express.js

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Project Structure
- `backend/` - Backend server and API
- `blog_application/` - Frontend pages, CSS, and JavaScript
- `postman/` - API testing resources

## How to Run
1. Install Node.js and MongoDB.
2. Open the backend folder in a terminal.
3. Run `npm install` to install dependencies.
4. Start the backend using the start command configured in `package.json`.
5. Open the frontend using VS Code Live Server.

## Project Purpose
This project was developed to practise full-stack web development, REST APIs, database integration, and CRUD operations.
