# InkWell Blog Application (Frontend)

## Features
- Home page with sample posts and live search
- Login and register forms with client-side validation
- Dashboard to create, edit, and delete user-created posts
- Responsive layout for mobile and desktop
- Browser `localStorage` for demo post persistence

## Run locally
1. Extract the ZIP.
2. Open the `blog_application` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Try Create a blog, publish it, and view it in Dashboard.

## Important limitations
This is a frontend learning demo. Login and registration do not authenticate users, and account credentials are not stored. `localStorage` is local to the current browser and is not a shared database. Do not enter real passwords or sensitive information. A production app needs a backend, secure authentication, authorization, and database storage.
